# Van Tri Phung – Portfolio

## Description
Professional portfolio website for Van Tri Phung, highlighting projects, skills, and contact information.

## Project Structure

```text
my-portfolio-react/
├─ src
│  ├─ components      # Components (About, Footer, Intro, Navbar, Projects, and Skills)
│  ├─ main.jsx        # App entry point
│  ├─ index.css       # Global styles
├─ public             # Image, logo, icon, file
```

## Portfolio Sections

- Short introduction
- About
- Skills
- Projects
- Footer

## Technologies

- React 19
- TypeScript
- Vite
- Bootstrap 5 for UI

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vanphungvnu/my-portfolio-react.git
cd my-portfolio-react
```

### 2. Install dependencies

```bash
npm install
```

### 3. Scripts

```bash
# Run the app
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
